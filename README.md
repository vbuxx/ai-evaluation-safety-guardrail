# Project ini mengevaluasi dan memperbaiki IT Helpdesk Assistant.

Assignment 5 melanjutkan sistem assignment 4 milik sendiri. Evaluasi menggunakan
12 skenario resmi dan empat kategori safety dari brief. Hasil aktual dan laporan
analisis dilengkapi setelah baseline dan versi perbaikan dijalankan.

Kamu memasang dependency sistem dan evaluasi dengan
`pip install -r system/requirements.txt -r requirements.txt`, lalu mengisi
`system/.env` berdasarkan `system/.env.example`.

Kamu menjalankan evaluasi dengan
`python evaluation/run_evaluation.py --phase before` atau `--phase after`.
